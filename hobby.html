งานอดิเรก

ผมใช้เวลาว่างหรือแม้แต่เวลาทำงานบางครั้งในการทำสิ่งที่ผมชอบจากงานอดิเรกจนบางอย่างสามารถสร้างอาชีพให้ผมได้

ทำเว็บไซต์

ผมใช้เวลานอกจากการเรียนรับทำเว็บไซต์(content) ด้วย WordPress เช่น ขึ้นโครงเว็บ, ออกแบบดีไซต์ตาม Ref แก้ธีมปลั๊กอิน หรือทำระบบต่างๆที่ไม่ได้ซับซ้อนมาก จนถึงดูแลเว็บไซต์ อัปเดตระบบต่างๆภายในเว็บไซต์ Backup ข้อมูลรายวันรายสัปดาห์ ฯลฯ ปัจจุบันผมดูแลเว็บไซต์กว่าสิบเว็บไซต์ โดยแกติจะรับเว็บใหม่ช่วงปิดเทอม ในช่วงเปิดเทอมจะรับแค่ดูแลเว็บ

เขียนบล็อก

ผมเขียนบล็อกบันทึกเกี่ยวกับตัวผมเอง หรือแม้แต่แบ่งปันข้อมูลต่างๆ เขียนมาเกือบ 4 ปีแล้ว

หาซูลูชันใหม่ๆเกี่ยวกับการทำเว็บ

เทคโนโลยีเว็บในปัจจุบันนั้นไปเร็วมากๆ จนบางทีผมเองก็ตามไม่ทันจนเลิกตามเทรนด์ใหม่ๆ แล้วหันมาโฟกัสเฉพาะงานของตัวเอง อย่างผมทำเว็บ Content ต้องการหาโจทย์ว่าอยากได้เว็บที่มีหลายพันหน้าไปจนถึงหลักหมื่นหลักแสนได้ รองรับผู้เข้าชมหลายล้านต่อวันโดยที่ Server ไม่ล่มแล้วประหยังค่าใช้จ่าย Server ที่สุด และไม่ต้องมาคอยดูแลอัปเดต Server อย่าง WordPress ในปัจจุบัน จนไปเจอ nextjs ที่ผมมองว่าเหมาะกับ Wep Apps มากกว่า และไปเจอ Astro ที่รองรับ CMS ทุกรูปแบบและตอบโจทย์ทุกอย่างที่ผมกล่าวมา
